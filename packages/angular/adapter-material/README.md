# @adapttable/angular-material

A private placeholder. This package is not built and not published yet.

It will be the Angular `DataTable` with every slot filled by Angular Material
(`@angular/material` on npm) components, built on the Angular unstyled adapter. The
work is tracked in
[#467](https://github.com/orwa-mahmoud/adapttable/issues/467).

The folder exists now so the kit is already registered in
`scripts/kits.mjs` and the workspace; the pull request that builds the kit
fills in its sources, build, tests and exports.
